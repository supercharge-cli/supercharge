# Supercharge 1.4.2

## Added
- OpenCode Go (`opencode-go`) and OpenCode Zen (`opencode-zen`) as separate `/setup` providers, each with its own API key. Chat uses the documented OpenCode inference endpoints. Zen hides official-app free models.
- Mistral `/credits` opens a popup with percent used, dollars spent, and a loading spinner while the balance is fetched.
- Mistral browser sign-in retries HTTP 429 on poll and exchange.

## Fixed
- Mistral chat streams accept content parts and object tool arguments, and unnamed shell calls map to `run_terminal_cmd`.
- Queued slash commands other than `/compact` no longer start compaction.
