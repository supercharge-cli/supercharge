# Supercharge 1.4.5

## Added

- Custom chat agents. Create one with `/new_agent` (paste a full prompt, or let the chat draft it) or with `n` in `/agents`.
- Shift+Tab walks Agent, Plan, Ask, your custom agents, Always-Approve, and Auto-Review.
- Studio chat menu can create the same agent over ACP. The CLI writes the markdown file.

## Changed

- Skills and plugin agents no longer appear in Shift+Tab or `/agents`. Only agents you create do.
