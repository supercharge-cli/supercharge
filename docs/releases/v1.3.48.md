# Supercharge 1.3.48

## Fixes

- **Chat Completions 400 "Extra inputs are not permitted, field: messages[N].model_id"**: assistant messages no longer send the internal `model_id` field to providers. Strict OpenAI-compatible providers rejected it. Saved sessions still record which model wrote each reply.
- **Responses "missing field output_tokens_details"**: when a provider leaves out `input_tokens_details` or `output_tokens_details` (or a usage counter), those values now default to 0 and the response parses normally.

## Upgrade

```
curl -fsSL https://raw.githubusercontent.com/supercharge-cli/supercharge-releases/main/install.sh | bash
```
