# Supercharge AI v1.3.47

## Memory recall

- Each turn, memory searches your saved notes for the current request (keyword
  search, BM25) and adds up to 4 matching snippets, at most about 1.2k tokens,
  as a hidden reminder. Weak matches are left out, and a note already shown in a
  session (including a resumed one) is not shown again.
- The agent can search and read notes itself with `memory_search` and `memory_get`.
- Tune or turn off with `[memory_v2] recall_enabled`, `recall_max_results`,
  `recall_max_tokens`, `recall_min_score`.

## Cheaper automatic capture (opt-in)

- `[memory_v2] capture_trigger = "off" | "session_end" | "compaction" | "turn"`
  (default `session_end`: one extraction call per session).
- `capture_model` picks a smaller model (falls back to `[models] session_summary`,
  then the session model). Extraction output is capped at 2k tokens.
- Trivial turns are skipped without a model call, and observations memory
  already holds are dropped.

## Memory upkeep

- Memory records when each topic note was created and last used; recall
  snippets show these dates.
- After Dream (and at session start), near-duplicate topics are merged into the
  most recently used one, and topics unused for `stale_days` (default 90; `0`
  keeps everything) move to `archive/topics/`, where you can move them back.
- Adding a new topic that nearly duplicates an existing one is refused with a
  hint to edit the existing note instead.
- One curated project note per project,
  `~/.supercharge/memory-v2/projects/<workspace id>/PROJECT.md` (at most 1500
  characters), is shown in full at session start.

## Changes to note

- The legacy memory pipeline now needs `[memory] mode = "legacy"`.
  `[memory] enabled = true` or `SUPERCHARGE_MEMORY=1` now turns on memory v2.
- `[memory_v2] enabled = false` turns memory off (it used to fall back to legacy
  memory).
- Memory archives are no longer included in turn trace uploads.
- The memory log target is now `supercharge_memory`
  (for example `RUST_LOG=supercharge_memory=debug`).
- ACP: the memory extensions are now `_supercharge/memory/flush`, `/dream`,
  `/rewrite`, and `/forget`, and the session meta key is
  `_supercharge/memoryMode`. The previous names are still accepted and the
  previous meta key is still sent.
- Headless `-p` runs with a key configured in `[model.*]` no longer fail with
  "No provider credentials are configured".

## Turning memory off

Any one of these:

```toml
# ~/.supercharge/config.toml
[memory_v2]
enabled = false
```

- `[memory] enabled = false` in `~/.supercharge/config.toml`
- `SUPERCHARGE_MEMORY=0` (environment variable)
- `supercharge --no-memory` (one run)
