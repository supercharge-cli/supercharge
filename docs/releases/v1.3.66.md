# Supercharge 1.3.66

1.3.65 was tagged but never published: its macOS builds failed to compile. This release includes every change listed in the [1.3.65 notes](v1.3.65.md), plus the fix below.

## Fixed
- macOS: the sandbox crate builds again for Apple Silicon and Intel. The deny-glob helpers that the Seatbelt per-command backend uses (glob root splitting, deny-glob validation, regex filters and anchored glob regexes) are available on macOS whether or not the `enforce` feature is on.
- Sandbox tests: the bubblewrap re-exec marker in the end-to-end tests now uses the current `__SUPERCHARGE_INSIDE_BWRAP` name. The genuine devbox re-exec test is skipped on hosts without `/data`, because devbox needs no re-exec there.
