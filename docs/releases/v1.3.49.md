# Supercharge 1.3.49

## Fixes

- **"serialization error: invalid type: null, expected u32"**: providers that send `null` for token counts, indexes, sequence numbers or timestamps no longer break a turn. Those values are treated as 0, and other `null` fields fall back to their defaults.
- This applies to Responses, Chat Completions and Messages, in both streaming and non-streaming replies. It also covers missing usage counters, missing or `null` usage details, `null` finish or stop reasons, and missing or `null` `choices`.
- Well-formed replies are parsed exactly as before. The lenient retry only runs when strict parsing fails.

curl -fsSL https://raw.githubusercontent.com/supercharge-cli/supercharge-releases/main/install.sh | bash
