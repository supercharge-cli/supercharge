# Supercharge 1.4.3

Builds on 1.4.2 (which was never tagged; this release includes it).

## Added

- ChatGPT (Codex) provider plumbing: OAuth browser sign-in with the Codex CLI's PKCE flow, token storage and refresh compatible with `~/.codex/auth.json`, and a curated model catalog. Hidden from the setup picker for now while the ChatGPT codex Responses stream settles.
- Optional local browser tools with a headless Chromium/CDN runtime and a file-acceleration feature flag.
- Built-in eval smoke presets (Rust, web).
- Mistral `/credits` popup with percent used, dollars spent, and a loading spinner.
- OpenCode Go and OpenCode Zen as separate `/setup` providers (included 1.4.2 work, first release carrying it).

## Fixed

- Responses-format providers: system prompts move to the `instructions` field instead of a system message in `input` (fixes 400 "System messages are not allowed" on strict backends).
- Credential sources register on every agent startup path, fixing 401s on the TUI daemon path.
- Mistral sign-in retries HTTP 429 on poll and exchange; Mistral streams accept content parts and object tool arguments; unnamed shell tool calls map to `run_terminal_cmd`.
- Queued slash commands other than `/compact` no longer start compaction.
