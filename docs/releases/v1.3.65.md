# Supercharge 1.3.65

Covers all changes since 1.3.51 (including 1.3.60 and 1.3.61).

## Added
- Sandbox: per-command sandbox policy and grants with a Linux bubblewrap backend, an exact-origin egress proxy for sandboxed commands, a workspace sandbox gate with network decisions and permission cards, plus sandbox settings and telemetry events.
- Reverse engineering: native binary, ASAR, APK, disassembly and capture tools, and a built-in reverse-engineering skill toggled with `/REA-mode on|off`.
- Memory: `/memory` list and toggle, cached content search (all-terms match, jump to first hit), drag-select to copy from the preview, and narrow-terminal support with keyboard focus on the preview.
- Voice: clip transcription through the provider's `/audio/transcriptions` endpoint, per-session voice events and a transcribing state.
- Skills tab lists per-session skills; reload rescans and unreadable folders are shown.
- Agents can overlay their own `mcpServers` onto the session; subagents can optionally inherit the parent model.
- Sampler: robust 429 retry that honours server wait hints, configurable `[retry]` limits and cancellable waits.
- Prompt: image placeholders stay bound across yank, undo, history and rewind; Ctrl+Z right after a stash restores it; textarea restores a removed element over its original range.
- Per-model notice shown above the prompt; `worktree create --ref`; attached session images carried across compaction; turns left unfinished by a crashed process are recorded.
- MCP connector arguments are coerced to the tool schema, with a reminder to the model.
- Minimal mode reprints history at the new width after a resize.
- Settings import from other coding agents moved into its own crate, now `/import-settings` (old command kept as an alias).
- New provider preset in `/setup`.

## Fixed
- Chat-completions requests no longer drop image attachments when the system prompt is folded into the first user message, so image recovery and vision prompts work on providers without a system role.
- Model picker Enter accepts the highlighted row instead of the raw search text.
- Tool names are sanitized (with reverse mapping) for strict providers, including on compaction requests.
- Signal streams are claimed before spawning so early signals restore the terminal.
- Mixed-case `reasoning_effort` values and the effort label shown in the picker are accepted.
- Parallel subagents are counted in the wait status; queued-prompt edits return focus to the composer.
- Compaction honours the model's request size cap when budgeting images.
- Permission prompts hard-wrap long quoted arguments; search and edit rows show failure reasons.
- Memory captures drop encrypted reasoning blobs and keep the summary; settled tombstones skip manifest rebuilds.
- Settings import redacts environment values in its list.
- Workspace `redirect_events` RPC is implemented and the fork sha check verifies the seed commit.

## Changed
- Internal identifiers, headers, request fields, metadata keys, tool namespace and client name renamed to Supercharge names. Legacy ids, headers and keys are still read, so existing sessions and configs keep working.
- Documentation uses generic model names in examples.
