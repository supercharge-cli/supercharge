# Supercharge 1.3.50

## Features

- **/models live list**: opening `/model` (or `/models`) with no argument seeds the catalog and refreshes the live provider model list in the background, so the picker shows current models instead of a stale or empty list.
- **Unknown typed model id**: if you type a model id that is not in the list and press Enter, the CLI asks once whether to use that id. Press Enter again to use it, or Esc to cancel.

## Upgrade

```
curl -fsSL https://raw.githubusercontent.com/supercharge-cli/supercharge-releases/main/install.sh | bash
```
