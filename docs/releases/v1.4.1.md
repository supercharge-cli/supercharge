# Supercharge 1.4.1

Builds on 1.4.0 with settings/feature ports for subagent model inheritance and a home file-lock helper used by leader acquire.

## 1.4.0 (included)

### Added
- Offline eval harness (`supercharge eval`): grade agents against JSONL task datasets in isolated git worktrees, with pass@k summaries and a best-of-N runner that keeps the winning patch.
- Hosted plugin catalog surfaced in plugin slash commands and marketplace flows (alongside the existing self-hosted plugin packages).

### Changed
- Plugin account connections accept only `_supercharge/connections/*` ACP methods. Legacy connection method names are no longer routed.

### Fixed
- Linux CI installs D-Bus headers so secret-service builds succeed in clean environments.

## 1.4.1

### Added
- Subagent model inheritance as a proper Feature (`[features] subagent_model_inheritance`) with settings UI, remote wire-up, and config-layer reseeding. The legacy `[subagents] inherit_model` key still works when the features key is unset.
- Bounded non-blocking advisory file-lock helper (`supercharge-file-lock`) for Supercharge home writes, used by leader lock acquire behind a machine-local acquire slot so a stalled network filesystem wedges at most one process per lock path.
