# Supercharge AI v1.3.46

## Memory is now on by default

- The agent keeps its own long-term memory across sessions. It saves preferences,
  corrections, decisions, and hard-won project facts when they are settled, reads
  only the topic files that match the task, updates existing notes instead of
  duplicating them, and removes notes that turn out to be wrong.
- Recall is cheap: only a compact index of titles and one-line descriptions
  (at most 3 KB per scope, global and per workspace) goes into the prompt.
- Fully local: Markdown and SQLite under `~/.supercharge/memory-v2/`, created with
  owner-only permissions (0700 directories, 0600 files). No upload, no remote service.
- No hidden model calls: automatic per-turn capture is off by default
  (opt in with `[memory_v2] capture_enabled = true`).
- Memory never stores secrets: writes that look like API keys, tokens, passwords,
  private keys, or credential URLs are refused (legacy session logs are masked).
- The always-loaded notes saved with the `memory` tool keep working as before.

## Turning memory off

Any one of these:

```toml
# ~/.supercharge/config.toml
[memory_v2]
enabled = false
```

- `[memory] enabled = false` in `~/.supercharge/config.toml`
- `SUPERCHARGE_MEMORY=0` (environment variable)
- `supercharge --no-memory` (one run)

An explicit `[memory] enabled = true` keeps the legacy memory system.
