# Supercharge 1.4.0

## Added
- Offline eval harness (`supercharge eval`): grade agents against JSONL task datasets in isolated git worktrees, with pass@k summaries and a best-of-N runner that keeps the winning patch.
- Hosted plugin catalog surfaced in plugin slash commands and marketplace flows (alongside the existing self-hosted plugin packages).

## Changed
- Plugin account connections accept only `_supercharge/connections/*` ACP methods. Legacy connection method names are no longer routed.

## Fixed
- Linux CI installs D-Bus headers so secret-service builds succeed in clean environments.
