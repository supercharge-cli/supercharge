# Supercharge 1.3.60

## New
- AgentRouter is now a built-in `/setup` provider. Requests to agentrouter.org carry the ZCode client identity it requires (user-agent, referer, `x-zcode-*` headers) plus fresh request ids per call, including the models-catalog fetch during setup. Uses the Responses API; models: `gpt-5.6-sol`, `gpt-6.1-sol`, `gpt-6-astra`.
