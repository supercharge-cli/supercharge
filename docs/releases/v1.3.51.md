# Supercharge 1.3.51

## Fixes
- Static API-key 401s now show the provider's real error instead of a misleading "run /setup" banner.
- Fixed empty `tool_call_id` in streamed tool calls; every request now repairs tool-call/result pairing, so affected sessions continue working.
- Chat Completions requests are normalized for strict providers (merged consecutive roles, empty content handled, stray fields removed).
- Streaming tolerates blank and non-JSON SSE lines and `[DONE]` variants.
- Sessions with a torn or partially written history line load instead of failing.
