# Supercharge 1.3.80

## Added
- Self-hosted plugins shared by the CLI and desktop app: portable `plugin.json` / `mcp.json` / `skills/` packages, catalog install, and enable, disable, update, and uninstall.
- Built-in Microsoft Learn and GitHub plugins (1.0.0). GitHub includes a draft-only Release Brief skill.
- Account connections on the selected agent: named accounts, bearer tokens, OAuth client setup, keychain storage with an owner-only file fallback, and an explicit HTTPS callback for a personal remote agent.
- `supercharge plugin catalog` and `supercharge plugin agent` for plugin and connection management. See `docs/plugins/README.md`.
