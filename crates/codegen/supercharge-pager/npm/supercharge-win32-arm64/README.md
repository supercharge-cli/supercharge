# @supercharge-cli/supercharge-win32-arm64

Platform-specific binary for [`@supercharge-cli/supercharge`](https://www.npmjs.com/package/@supercharge-cli/supercharge) on win32-arm64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @supercharge-cli/supercharge
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
